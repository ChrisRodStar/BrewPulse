# BrewPulse

Homebrew updates at a glance.

BrewPulse is a native macOS menu-bar app that monitors software installed through Homebrew, reports available updates, and provides a safe way to update packages without working directly in Terminal.

## Projects

- `macOS/` — Native Swift and SwiftUI application
- `website/` — Public Astro website
- `dashboard/` — Next.js account and license portal
