# BrewPulse documentation

Repository entry points remain at the root: `README.md`, `TODO.md`, `AGENTS.md`, `CHANGELOG.md`, `CONTRIBUTING.md`, and `SECURITY.md`.

Supporting documentation is organized here:

- [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) defines the approved native app visual system.
- [`ANALYTICS.md`](ANALYTICS.md) defines metrics, allowed events, and the analytics privacy boundary.
- [`PRIVACY.md`](PRIVACY.md) explains what leaves the Mac and what remains local.
- [`BETA.md`](BETA.md) covers preview installation, verification, and removal.
- [`SUPPORT.md`](SUPPORT.md) directs users to the right support and security channels.
- [`RELEASING.md`](RELEASING.md) documents packaging, publication, and update-feed work.

Implementation status belongs in the root `TODO.md`, not in a second roadmap under `docs/`.
