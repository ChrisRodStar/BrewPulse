# Support

## Bugs and feedback

Use [GitHub Issues](https://github.com/ChrisRodStar/BrewPulse/issues) for reproducible bugs and [GitHub Discussions](https://github.com/ChrisRodStar/BrewPulse/discussions) for questions and beta feedback.

Before opening an issue:

1. Refresh once more and note whether BrewPulse kept an older snapshot.
2. Open the failure or operation details and copy the preserved Homebrew output.
3. Include the BrewPulse version, macOS version, Mac architecture, and `brew --version` result.
4. Remove usernames, local paths, tokens, or other private details from copied output.

Do not post suspected security vulnerabilities publicly. Follow [SECURITY.md](../SECURITY.md) instead.

Analytics delivery is silent by design. If you report missing anonymous events, include the BrewPulse version and whether **Settings → Privacy → Share anonymous usage statistics** is enabled. Do not post installation IDs, queued event data, backend exports, or service credentials.

## Scope of the beta

The public 0.2.4 release covers Homebrew discovery, the Overview and Updates interface, individual updates, reviewed Update All, cancellation, failure recovery, user-approved in-app updates, and anonymous product analytics with an in-app opt-out. Requests for paid automation, accounts, fleet management, or hosted services are outside BrewPulse Free.
